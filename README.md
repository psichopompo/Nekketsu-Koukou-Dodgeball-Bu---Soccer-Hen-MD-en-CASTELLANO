# Nekketsu-Koukou-Dodgeball-Bu---Soccer-Hen-MD-en-CASTELLANO
Primera traducción a un idioma occidental de Nekketsu Koukou Dodgeball Bu - Soccer Hen MD (Mega Drive, 1992). Todo el texto y los gráficos en español: diálogos, menús, nombres de equipo y rótulos. Parches BPS e IPS para ROM japonesa sin cabecera.
